# Glossary

- **CI (continuous integration):** an automatic run of the tests on every push to the repository.
- **Gate:** a check that must pass before work moves to the next stage; if it fails, work stops until it is fixed.
- **Ruling:** a recorded answer to a question that came up during the build, with the cost of being wrong.
